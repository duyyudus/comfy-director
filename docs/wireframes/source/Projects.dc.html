Switching project changes the sequences, loose shots, Gallery and Compare to that project. Prompts, prompters and workflows are shared by all projects. The queue shows jobs from every project.
2New project
Create project dialog.
A project keeps its sequences, loose shots, renders and input images in one folder. Renaming the project renames the folder.
Also the third step of first launch ("First project"). After it, the screen shows "Start your first shot".

File paths inside a project are stored relative to the project folder, so a project can be renamed, moved or archived as a whole.
